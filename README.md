# Hue & Tone Palette Playground

色相（Hue）とトーン（Tone）をベースにした配色ツールです。
**メインはサンプルWebサイト**で、配色ルール・トーン・色相をオプションとして変更すると、その配色でサンプルWebサイトがリアルタイムに塗り替わります。
`index.html` 1 ファイルで完結しており、ビルド不要・外部 CDN 依存なしで GitHub Pages にそのまま公開できます。

---

## 特徴

- **サンプルWebサイトがメイン** — ナビゲーション・ヒーロー・機能カード・統計・お客様の声・料金プラン・CTA・フッターを備えた、実際のWebサイト風のサンプルをページ全体に表示
- **配色はフローティングパネル** — サンプルWebサイトの上に重ねたフローティングカードで色相・トーン・配色ルール・色数を変更すると、サンプルWebサイトの色が即座に反映される（ドラッグで移動可能・折りたたみ可能）
- **色相 × トーン**の二軸で配色を組み立てる（PCCS のトーン体系に相当する 10 トーン）
- **配色設定と色の関係を統合** — 配色設定と色の関係ビジュアライゼーション（トーンマップ・色相環）を 1 つのセクションにまとめ、色同士の位置関係を大きく可視化
- 色相を変えても**トーンの印象が保たれる**（トーンごとの彩度・明度レンジ内に必ず収め、色相による見た目の明るさの差も補正）
- パレットの色は**背景・文字・アクセント・カード面**などの役割に自動で割り当てられ、コントラスト比を保って読みやすく配置される
- 生成結果は**ランダム生成・手動調整・URL 共有**のいずれからも再現できる
- **パレット・エクスポート・履歴は折りたたみ** — 普段は隠しておき、必要なときに展開して表示

## 機能一覧

### 配色ルール

| ルール | 内容 |
| --- | --- |
| 単色（Monochromatic） | 同一色相のまま明度・彩度だけを変化させる |
| 類似色（Analogous） | 隣り合う色相（±30°） |
| 補色（Complementary） | 色相環の正反対（+180°） |
| 分裂補色（Split Complementary） | 補色の両隣（±150°） |
| トライアド（Triadic） | 色相環を三等分（±120°） |
| テトラード（Tetradic） | 色相環を四等分（+90 / 180 / 270°） |
| トーンオントーン | 同一色相・トーン違い |
| トーンイントーン | 同一トーン・色相違い |

### トーン

ペール / ライト / ブライト / ビビッド / ストロング / ディープ / ダル / ソフト / ダーク / グレイッシュ の 10 種類。
各トーンは「彩度の範囲・明度の範囲」として定義され、トーンマップ上に**彩度（横軸）× 明度（縦軸）**で二次元配置されています。

### 操作

- **ランダム生成** — ボタン 1 つ（または <kbd>Space</kbd> キー）で基準色相・トーン・配色ルールをランダムに決めて再生成
  - 「固定」チェックボックスをオンにした項目（色相 / トーン / ルール）はランダム化の対象外
- **手動調整** — 色相スライダー（0–360、背景が色相グラデーション）／トーンマップ／配色ルール／色数（2〜6）
- **サンプルWebサイト** — 現在の配色で塗られた Web サイト風のサンプルをページ全体に表示。配色を変えると即座に反映される
- **配色設定と色の関係（統合）** — 配色設定と、現在のパレットの全色を色をつけたトーンマップ（彩度×明度）・色相環に番号付きでプロットするビジュアライゼーションを 1 つのセクションに統合
- **カラーカード** — HEX / HSL / トーン名を表示。クリックで HEX をクリップボードにコピー（トーストで通知）。横に広いレイアウトで情報を整理
  - カードごとに彩度・明度を微調整でき、**カード単位でロック**すればランダム生成しても保持される
- **エクスポート** — HEX リスト / CSS カスタムプロパティ / Tailwind 風の設定オブジェクト / JSON をコピー（折りたたみセクション）
- **共有 URL** — 現在の状態を URL クエリに反映（リロード・共有で再現可能）
- **アクセシビリティ補助** — 各色と白／黒とのコントラスト比（WCAG）を計算し、AAA / AA / AA大 / NG のバッジで表示
- **履歴** — 直近 10 件の生成結果を保持し、クリックで復元（メモリ上・折りたたみセクション）
- **パネルの移動・折りたたみ** — ヘッダーをドラッグしてパネルを移動でき、ボタンで折りたたみ可能

### 共有 URL のクエリパラメータ

| パラメータ | 内容 | 例 |
| --- | --- | --- |
| `h` | 基準色相（0–360） | `h=210` |
| `tone` | トーン ID（`pale` `light` `soft` `bright` `grayish` `dull` `strong` `vivid` `dark` `deep`） | `tone=vivid` |
| `rule` | 配色ルール ID（`mono` `analogous` `complementary` `split` `triadic` `tetradic` `toneOnTone` `toneInTone`） | `rule=triadic` |
| `n` | 色数（2–6） | `n=5` |

例: `index.html?h=210&tone=vivid&rule=triadic&n=5`

### キーボードショートカット

| キー | 動作 |
| --- | --- |
| <kbd>Space</kbd> | ランダム生成（入力欄・ボタンにフォーカスがある場合を除く） |

## ローカルでの動かし方

`index.html` をブラウザで開くだけで動作します。

```sh
git clone https://github.com/<ユーザー名>/palette-playground.git
cd palette-playground
open index.html        # macOS（Windows は start、Linux は xdg-open）
```

クリップボードへのコピーはセキュアコンテキスト（`https://` または `localhost`）で安定して動作します。
`file://` で挙動が気になる場合は簡易サーバー経由で開いてください。

```sh
python3 -m http.server 8000
# → http://localhost:8000/
```

## GitHub Pages での公開手順

1. このリポジトリを GitHub に push する
2. リポジトリの **Settings → Pages** を開く
3. **Build and deployment → Source** で **GitHub Actions** を選択する
4. `main` ブランチに push すると `.github/workflows/deploy.yml` が実行され、リポジトリ直下の静的ファイルがそのまま配信される
5. 数十秒後に `https://<ユーザー名>.github.io/palette-playground/` で公開される

ワークフローは Actions タブから手動実行（`workflow_dispatch`）することもできます。

## 配色理論の簡単な解説

### 色相（Hue）

色みそのもの。0–360° の色相環で表され、赤 → 黄 → 緑 → 青 → 紫 と循環します。
配色ルールは「基準の色相から他の色相をどの角度に置くか」で決まります。角度が近いほど穏やかに、遠いほど対比が強くなります。

- **類似色（±30°）** — 色相差が小さく、まとまりやすい。落ち着いた印象
- **補色（+180°）** — 最も対比が強い。アクセントを立てたいときに有効
- **分裂補色（±150°）** — 補色の緊張をやわらげつつ対比を残す
- **トライアド（±120°）／テトラード（90°刻み）** — 色相環を均等に分割し、賑やかでバランスの取れた配色になる

### トーン（Tone）

**明度と彩度の組み合わせ**を、印象を表す言葉でまとめたものです（PCCS のトーン概念に相当）。
「ビビッドな赤」と「ビビッドな青」は色相が違っても同じ勢いを感じさせます。これがトーンの働きです。

| トーン | 印象 | おおよその彩度 / 明度 |
| --- | --- | --- |
| ペール | 淡い・やわらかい | S 22–34% / L 84–90% |
| ライト | 明るい・軽快 | S 44–58% / L 70–78% |
| ソフト | おだやか・穏健 | S 40–52% / L 58–66% |
| ブライト | 健康的・明快 | S 78–92% / L 58–66% |
| グレイッシュ | 地味・落ち着き | S 10–20% / L 46–56% |
| ダル | 鈍い・中間的 | S 32–44% / L 44–54% |
| ストロング | 強い・充実 | S 66–80% / L 44–52% |
| ビビッド | 鮮やか・目立つ | S 92–100% / L 46–54% |
| ダーク | 暗い・重厚 | S 55–70% / L 20–28% |
| ディープ | 深い・濃厚 | S 82–96% / L 28–36% |

- **トーンイントーン配色** — トーンを揃えて色相を変える。色数が多くても印象が散らからない
- **トーンオントーン配色** — 色相を揃えてトーン（主に明度差）を変える。統一感が最も高い

### コントラスト比（WCAG）

文字と背景の読みやすさの指標で、1〜21 の比率で表されます。本ツールでは各色と白／黒の比率を計算して表示します。

| 比率 | 判定 | 用途の目安 |
| --- | --- | --- |
| 7.0 以上 | AAA | 本文に十分 |
| 4.5 以上 | AA | 本文の最低ライン |
| 3.0 以上 | AA大 | 大きな文字（18pt 以上等）や UI 部品の境界 |
| 3.0 未満 | NG | 文字色としては避ける |

## 実装メモ

`index.html` の `<script>` は責務ごとにセクション分けされています。

| セクション | 内容 |
| --- | --- |
| 1. 定数 | しきい値・補正強度などのマジックナンバーを集約 |
| 2. 色変換ユーティリティ | `hexToRgb` / `rgbToHex` / `rgbToHsl` / `hslToRgb` / `hslToHex` / `hexToHsl`、相対輝度・コントラスト比 |
| 3. トーン定義 | `TONES` テーブル（彩度・明度レンジとトーンマップ上の位置）でトーンを一元管理 |
| 4. 配色ルール | `RULES` テーブル（色相オフセット、または特殊モード） |
| 5. パレット生成 | 設定 → HSL 配列 |
| 6. 状態 | 単一の `state` オブジェクト（DOM からは読み戻さない） |
| 7〜9. 履歴 / URL / エクスポート | スナップショット、クエリ同期、4 形式の出力 |
| 12. 役割割り当て | `buildSiteRoles` がパレットの色を背景・文字・アクセント・カード面などの役割に割り当てる |
| 13. サンプルWebサイト | `renderSite` が Web サイト風のサンプルを配色で描画する |
| 13.5 色の関係ビジュアライゼーション | `renderToneViz` / `renderWheelViz` が現在のパレットをトーンマップ・色相環にプロットする |
| 14〜15. 描画 / イベント | コントロール・パレット・エクスポート・履歴の描画、イベント登録 |
