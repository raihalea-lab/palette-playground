# Hue & Tone Palette Playground

色相（Hue）とトーン（Tone）をベースにした配色ツールです。
`index.html` 1 ファイルで完結しており、ビルド不要・外部 CDN 依存なしで GitHub Pages にそのまま公開できます。

---

## 特徴

- **PCCS の色相環（24 色相）とトーンマップ（12 トーン ＋ 無彩色 5 段階）を横に並べ、どちらもクリックで操作できる**
- 2 つの図が色空間を分担するため、**組み合わせですべての色を指定できる**
  - 色相環 = 色相（H）／トーンマップ = 彩度（S）× 明度（L）
  - 色相をもたない色は、トーンマップ左端の**無彩色の列**で選ぶ
  - PCCS の基準点（24 色相・12 トーン）は目安として図の上に置いてあり、その**間の色も自由に選べる**
- 色相を変えても**トーンの印象が保たれる**（色相による見た目の明るさの差を補正）
- 生成結果は**ランダム生成・手動調整・URL 共有**のいずれからも再現できる

## 機能一覧

### 配色ルール

| ルール | 内容 |
| --- | --- |
| 単色（Monochromatic） | 同一色相のまま明度・彩度だけを変化させる |
| 類似色（Analogous） | 隣り合う色相（±30°） |
| 補色（Complementary） | 色相環の正反対（+180°） |
| 分裂補色（Split Complementary） | 補色の両隣（±150°） |
| トライアド（Triadic） | 色相環を三等分（±120°） |
| テトラード（Tetradic） | 色相環を四等分（+90 / 180 / 270°） |
| トーンオントーン | 同一色相・トーン違い |
| トーンイントーン | 同一トーン・色相違い |

### 2 つの図

#### 色相環（PCCS 24 色相）

- 外周のリングは**連続した色相**。クリック／ドラッグで任意の角度を選べる
- 内側の 24 個の丸は **PCCS の色相番号**（1:pR 〜 24:RP）。8:Y が真上、時計回りに並ぶ
- 丸とリングの色は**現在のトーン**で描かれるため、「このトーンでこの色相はどう見えるか」がそのまま分かる
- 中心から伸びる線は、**現在のパレットが使っている色相**（配色ルールの効き方が一目で分かる）

#### トーンマップ（PCCS 12 トーン ＋ 無彩色）

- 面全体が「**彩度（横軸）× 明度（縦軸）**」の平面で、どこをクリックしても色を選べる
- 丸は PCCS の 12 トーン（v / b / s / dp / lt / sf / d / dk / p / ltg / g / dkg）の位置
- 左端の独立した列が**無彩色**（W / ltGy / mGy / dkGy / Bk）。ここを選ぶと色相をもたない配色になる
- 平面は**現在の色相**で描画され、パレットの各色が今どのトーンにいるかが点で示される

### 操作

- **図をクリック／ドラッグ** — 色相環で色相、トーンマップで彩度・明度を変更（PCCS の基準点はクリックでぴったり合わせられる）
- **ランダム生成** — ボタン 1 つ（または <kbd>Space</kbd> キー）で基準色相・トーン・配色ルールをランダムに決めて再生成
  - 「固定」チェックボックスをオンにした項目（色相 / トーン / ルール）はランダム化の対象外
- **手動調整** — 2 つの図／配色ルール／色数（2〜6）
- **カラーカード** — HEX / RGB / HSL / トーン名を表示。クリックで HEX をクリップボードにコピー（トーストで通知）
  - カードごとに彩度・明度を微調整でき、**カード単位でロック**すればランダム生成しても保持される
- **プレビュー** — 見出し・本文・ボタン・カード・背景に適用したサンプル UI で使用イメージを確認
- **エクスポート** — HEX リスト / CSS カスタムプロパティ / Tailwind 風の設定オブジェクト / JSON をコピー
- **共有 URL** — 現在の状態を URL クエリに反映（リロード・共有で再現可能）
- **アクセシビリティ補助** — 各色と白／黒とのコントラスト比（WCAG）を計算し、AAA / AA / AA大 / NG のバッジで表示
- **履歴** — 直近 10 件の生成結果を保持し、クリックで復元（メモリ上）

### 共有 URL のクエリパラメータ

| パラメータ | 内容 | 例 |
| --- | --- | --- |
| `h` | 色相環で選んだ色相（0–360） | `h=210` |
| `s` | トーンマップで選んだ彩度（0–100） | `s=100` |
| `l` | トーンマップで選んだ明度（0–100） | `l=52` |
| `ac` | 無彩色の列を選んでいるとき `1` | `ac=1` |
| `rule` | 配色ルール ID（`mono` `analogous` `complementary` `split` `triadic` `tetradic` `toneOnTone` `toneInTone`） | `rule=triadic` |
| `n` | 色数（2–6） | `n=5` |

例: `index.html?h=210&s=100&l=52&rule=triadic&n=5`

旧バージョンの `tone=vivid` のような指定も、対応する PCCS トーンとして読み込めます。

### キーボードショートカット

| キー | 動作 |
| --- | --- |
| <kbd>Space</kbd> | ランダム生成（入力欄・ボタンにフォーカスがある場合を除く） |

## ローカルでの動かし方

`index.html` をブラウザで開くだけで動作します。

```sh
git clone https://github.com/<ユーザー名>/palette-playground.git
cd palette-playground
open index.html        # macOS（Windows は start、Linux は xdg-open）
```

クリップボードへのコピーはセキュアコンテキスト（`https://` または `localhost`）で安定して動作します。
`file://` で挙動が気になる場合は簡易サーバー経由で開いてください。

```sh
python3 -m http.server 8000
# → http://localhost:8000/
```

## GitHub Pages での公開手順

1. このリポジトリを GitHub に push する
2. リポジトリの **Settings → Pages** を開く
3. **Build and deployment → Source** で **GitHub Actions** を選択する
4. `main` ブランチに push すると `.github/workflows/deploy.yml` が実行され、リポジトリ直下の静的ファイルがそのまま配信される
5. 数十秒後に `https://<ユーザー名>.github.io/palette-playground/` で公開される

ワークフローは Actions タブから手動実行（`workflow_dispatch`）することもできます。

## 配色理論の簡単な解説

### 色相（Hue）

色みそのもの。0–360° の色相環で表され、赤 → 黄 → 緑 → 青 → 紫 と循環します。
PCCS では、この輪を知覚上の見え方にもとづいて 24 等分し、1:pR（紫みの赤）〜 24:RP（赤紫）の番号で呼びます。
本ツールの色相環はこの 24 色相を丸で示しつつ、その間の角度も選べるようになっています。
配色ルールは「基準の色相から他の色相をどの角度に置くか」で決まります。角度が近いほど穏やかに、遠いほど対比が強くなります。

- **類似色（±30°）** — 色相差が小さく、まとまりやすい。落ち着いた印象
- **補色（+180°）** — 最も対比が強い。アクセントを立てたいときに有効
- **分裂補色（±150°）** — 補色の緊張をやわらげつつ対比を残す
- **トライアド（±120°）／テトラード（90°刻み）** — 色相環を均等に分割し、賑やかでバランスの取れた配色になる

### トーン（Tone）

**明度と彩度の組み合わせ**を、印象を表す言葉でまとめたものです（PCCS のトーン概念に相当）。
「ビビッドな赤」と「ビビッドな青」は色相が違っても同じ勢いを感じさせます。これがトーンの働きです。

| 記号 | トーン | 印象 | トーンマップ上の位置（S / L） |
| --- | --- | --- | --- |
| `p` | ペール | 淡い・やわらかい | S 30% / L 87% |
| `lt` | ライト | 明るい・軽快 | S 58% / L 78% |
| `b` | ブライト | 健康的・明快 | S 86% / L 70% |
| `ltg` | ライトグレイッシュ | 明るく穏やか | S 18% / L 74% |
| `sf` | ソフト | おだやか・穏健 | S 46% / L 64% |
| `v` | ビビッド | 鮮やか・目立つ | S 100% / L 52% |
| `s` | ストロング | 強い・充実 | S 78% / L 54% |
| `d` | ダル | 鈍い・中間的 | S 42% / L 50% |
| `g` | グレイッシュ | 地味・落ち着き | S 15% / L 52% |
| `dp` | ディープ | 深い・濃厚 | S 86% / L 36% |
| `dk` | ダーク | 暗い・重厚 | S 56% / L 28% |
| `dkg` | ダークグレイッシュ | 暗く渋い | S 16% / L 26% |

無彩色は W（白）／ltGy（明るい灰）／mGy（中位の灰）／dkGy（暗い灰）／Bk（黒）の 5 段階で、
トーンマップ左端の列にまとめてあります。

- **トーンイントーン配色** — トーンを揃えて色相を変える。色数が多くても印象が散らからない
- **トーンオントーン配色** — 色相を揃えてトーン（主に明度差）を変える。統一感が最も高い

### コントラスト比（WCAG）

文字と背景の読みやすさの指標で、1〜21 の比率で表されます。本ツールでは各色と白／黒の比率を計算して表示します。

| 比率 | 判定 | 用途の目安 |
| --- | --- | --- |
| 7.0 以上 | AAA | 本文に十分 |
| 4.5 以上 | AA | 本文の最低ライン |
| 3.0 以上 | AA大 | 大きな文字（18pt 以上等）や UI 部品の境界 |
| 3.0 未満 | NG | 文字色としては避ける |

## 実装メモ

`index.html` の `<script>` は責務ごとにセクション分けされています。

| セクション | 内容 |
| --- | --- |
| 1. 定数 | しきい値・補正強度などのマジックナンバーを集約 |
| 2. 色変換ユーティリティ | `hexToRgb` / `rgbToHex` / `rgbToHsl` / `hslToRgb` / `hslToHex` / `hexToHsl`、相対輝度・コントラスト比 |
| 3. PCCS の色相 | `PCCS_HUES` テーブルと、色相番号 ↔ HSL 角度の相互変換 |
| 4. PCCS のトーン | `TONES`（12 トーン）と `NEUTRALS`（無彩色 5 段階）。値はトーンマップ上の座標そのもの |
| 5. 配色ルール | `RULES` テーブル（色相オフセット、または特殊モード） |
| 6. パレット生成 | 選択位置（色相・彩度・明度） → HSL 配列。先頭の色は必ず図で選んだ色になる |
| 7. 状態 | 単一の `state` オブジェクト（DOM からは読み戻さない） |
| 8〜10. 履歴 / URL / エクスポート | スナップショット、クエリ同期、4 形式の出力 |
| 11〜14. DOM / 描画 / イベント | 2 つの図の canvas 描画、ピンの配置、ポインタ操作の登録 |

2 つの図は `<canvas>` で描画し、その上に PCCS の基準点を `<button>`（ピン）として重ねています。
canvas 側とピン側でジオメトリ（`WHEEL` / `PLANE`）を共有しているため、位置は常に一致します。
